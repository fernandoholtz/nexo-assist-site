# Vídeos demonstrativos do site

Esta pasta recebe os vídeos curtos exibidos na página comercial.

Arquivos esperados:

- `demo-os.mp4`
- `demo-vendas.mp4`
- `demo-gestao.mp4`

Os vídeos devem ser recortes do aplicativo real, sem dados pessoais de clientes, credenciais, tokens, e-mails reais, telefones reais ou outras informações sensíveis.

Para o site público, prefira vídeos:
- curtos;
- sem áudio;
- comprimidos para web;
- com dados fictícios/de demonstração;
- em H.264/MP4 com carregamento otimizado.

Os arquivos binários podem ser adicionados posteriormente a esta pasta sem alterar o HTML.
